# 微文收纳 · 公众号文章批量同步与归档系统

在「微信后台批量抓取不可用 + 微信 RSS 订阅下线（2026-08-03）」背景下，通过**浏览器扩展 + 本地客户端**混合架构，实现公众号文章的批量抓取、持续更新、属性管理与多格式本地导出。

## 核心能力

1. 浏览器扩展一键批量同步文章（源格式 HTML）
2. 粘贴任意文章链接 → 自动反查公众号并入库
3. 主页 key 分页抓取全部历史文章，替代 RSS 实现持续更新
4. 专辑页/合集批量同步
5. 同步范围：全部历史 / 最近 1·3·6 个月 / 1 年 / 自定义日期
6. 属性系统：作者、发布日期、文章链接、来源、自定义主题
7. 导出：html / json / excel / txt / md / docx（html 100% 还原样式）
