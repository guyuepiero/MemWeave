# 项目模板说明

这是新建项目时可复制使用的标准项目模板。

每个长期项目都建议拥有独立目录，避免项目记忆、代码、文档和数据混在一起。

## 目录结构

```text
PROJECT_NAME/
├── README.md
├── MEMORY.md
├── TASK.md
├── CODE/
├── DOCS/
└── DATA/
```

## 文件用途

### README.md

项目概览。

用于说明项目目标、背景、范围、主要模块和当前状态。

### MEMORY.md

项目长期记忆。

用于保存项目中长期有效的决策、规则、架构选择、经验和限制。

它不是会话总结，也不是任务清单。

### TASK.md

项目任务状态。

用于记录当前项目目标、已完成内容、进行中内容和下一步。

### CODE/

项目代码目录。

保存与该项目直接相关的代码、脚本、配置或程序文件。

### DOCS/

项目文档目录。

保存需求说明、设计文档、接口说明、研究文档和操作说明。

### DATA/

项目数据目录。

保存该项目使用或生成的数据文件。

## 使用规则

- 新项目从本模板复制。
- 每个项目独立维护自己的 `MEMORY.md` 和 `TASK.md`。
- 项目长期决策写入 `MEMORY.md`。
- 当前进度写入 `TASK.md`。
- 会话过程不要写入项目目录，应写入 `03_MEMORY/SESSION/`。
