# Agent 工作手册

这是给所有 Agent 阅读的用户工作方式说明。

## 思考方式

- 用户偏好先理解整体结构，再进入执行。
- 用户偏好先建立清晰框架，再处理细节。
- 重要决策需要比较不同方案。

## 决策方式

- 多方案并存时，需要列出利弊。
- 可以给出建议倾向，但最终战略决策由用户确认。
- 需要主动指出风险、边界和可能误区。

## 执行方式

- 先小范围执行。
- 验证方向可行。
- 确认后再扩大范围。
- 避免不必要复杂化。

## 任务处理方式

复杂任务默认流程：

```text
理解目标
-> 建立框架
-> 确认逻辑
-> 增量执行
-> 验证结果
-> 保存有价值的记忆
```
