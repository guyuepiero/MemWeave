# 用户画像

## 背景

跨境电商从业者，聚焦中国区亚马逊运营；同时是 AI Agent 的深度学习者与使用者，正在搭建个人知识库。三重身份：

1. **中国区亚马逊运营**：执掌全链路运营闭环，核心覆盖市场调研、竞品分析、Listing 上架与优化、广告投放、数据分析、库存管理及销售复盘。
2. **AI Agent 学习者与使用者**：使用并研究市面主流 Agent，方向覆盖 vibe coding、工具助手搭建、视频转笔记、知识库整理与 Agent 新功能研究。
3. **知识库搭建者**：以 Obsidian 为核心，借助 AI Agent 或插件，将知识源文件整理为可复用的结构化笔记。

## 目标

长期：构建一套以 AI_OS 为底座、多 Agent 协同、知识库沉淀的个人运营与研发工作流，让运营经验、爬虫能力与知识资产可复用、可继承。

当前战略目标：

- 完善 AI_OS v1.0 框架，使其能被多个 Agent 共享使用。
- 用 vibe coding 产出可用的亚马逊爬虫与跨境电商 / 国内平台工具助手。
- 把视频内容与碎片知识系统化沉淀进 Obsidian 知识库。

近期重点：搭建 AI_OS 框架规则与用户上下文。

## 常用领域

跨境电商运营（亚马逊为主）、AI Agent 应用与 vibe coding、Python 爬虫（Playwright + Chromium）、数据整理 / 分析 / 可视化、Obsidian 知识库与结构化笔记、视频内容转文字笔记、库存与销售复盘。

## 当前关注方向

### 方向 A — 电商平台爬虫（vibe coding）

用 Python 编写电商平台爬虫，技术栈为 Playwright + Chromium，目前主要用于亚马逊平台。

关键注意点：美区邮编、动态页面渲染、页面加载等待、反爬机制、数据格式清洗、模拟真人行为。

### 方向 B — 跨境电商与国内平台工具助手

搭建覆盖市场调研、选品分析、商品上架、竞品分析、数据整理 / 分析 / 可视化、库存管理、销售复盘的工具助手；平台不限于亚马逊，其余平台待补充。

### 方向 C — 视频转文字笔记

将社交平台视频内容（YouTube、抖音等）转化为文字版可用笔记，保存为 Markdown 文件，归档进 Obsidian 作为知识库。

### 方向 D — Obsidian 知识库整理

Obsidian 知识库的内容整理、分类检索、结构化笔记。

### 方向 E — AI Agent 新功能学习与研究

跟踪并研究各 Agent 的新功能、新能力，验证后运用到上述工作流。

### 框架

- 搭建 AI_OS v1.0，作为多个 Agent 共享的记忆系统与工作空间框架。
