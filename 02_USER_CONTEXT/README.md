# 02_USER_CONTEXT 用户上下文目录说明

本目录保存当前用户的长期上下文。

它用于让不同 Agent 在接管任务时理解同一个用户：用户是谁、如何工作、喜欢什么样的协作方式。

## 目录结构

```text
02_USER_CONTEXT/
├── README.md
├── USER.md
├── AGENTS.md
└── SOUL.md
```

## 文件用途

### USER.md

用户画像。

用于记录用户的基础信息、长期目标、常用领域和当前关注方向。

回答的问题是：

```text
这个用户是谁？
```

### AGENTS.md

Agent 工作手册。

用于记录用户希望 Agent 如何协助自己，包括思考方式、决策方式、执行方式和任务处理流程。

回答的问题是：

```text
Agent 应该如何与这个用户一起工作？
```

### SOUL.md

协作风格。

用于记录用户偏好的沟通方式、分析深度、风险提醒方式和边界要求。

回答的问题是：

```text
Agent 应该用什么风格与这个用户协作？
```

## 与系统规则的区别

```text
SYSTEM_RULES = Agent 必须遵守的底层规则
USER_CONTEXT = 当前用户的协作配置
```

如果发生冲突：

```text
SYSTEM_RULES > USER_CONTEXT
```

## 使用规则

- 用户上下文应保持稳定，不要频繁写入临时信息。
- 只有跨项目、长期有效的信息才适合写入本目录。
- 项目决策应写入项目 `MEMORY.md`。
- 会话过程应写入 `03_MEMORY/SESSION/`。
