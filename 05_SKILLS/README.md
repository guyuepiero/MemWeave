# 05_SKILLS 技能目录说明

本目录用于保存 Agent 可复用的技能。

技能不是知识资料，也不是项目文档，而是“完成某类任务的方法、流程或操作规范”。

## 目录结构

```text
05_SKILLS/
├── README.md
├── INDEX.md
├── SKILL_TEMPLATE.md
├── COMMON/
└── AGENT_SPECIFIC/
    ├── CODEX/
    ├── TRAE/
    ├── QODER/
    ├── WORKBUDDY/
    └── HERMES/
```

## INDEX.md 技能索引

### 用途

保存所有技能的导航表。

Agent 不应该直接扫描全部技能文件，而应该先读取 `INDEX.md`，判断当前任务需要哪个技能。

### 适合记录

- 技能名称
- 技能用途
- 适用任务
- 文件路径
- 所属 Agent 或通用范围

## SKILL_TEMPLATE.md 技能模板

### 用途

新建技能时使用的标准模板。

用于保证每个技能都有清晰的输入、步骤、输出和验证方式。

## COMMON/ 通用技能区

### 用途

保存所有 Agent 都可以使用的技能。

### 适合放入

- 研究流程
- 写作流程
- 总结流程
- 数据分析流程
- 知识整理流程
- 任务拆解流程
- 项目复盘流程

### 不适合放入

- 某个 Agent 独有的操作方式
- 某个项目专属流程
- 外部知识资料

## AGENT_SPECIFIC/ Agent 专属技能区

### 用途

保存不同 Agent 的专属技能和工作方式。

### 子目录说明

```text
CODEX/
= 编程、调试、本地仓库、代码修改、测试验证相关技能

TRAE/
= IDE 工作流、应用构建、前端开发协作相关技能

QODER/
= 编程辅助、代码生成、项目开发相关技能

WORKBUDDY/
= 工作流管理、任务协调、计划推进相关技能

HERMES/
= 研究、资料分析、信息整理相关技能
```

## 读取规则

```text
先读取 INDEX.md
-> 判断任务类型
-> 读取 COMMON 或 AGENT_SPECIFIC 中的目标技能
-> 执行技能步骤
-> 验证输出
```

## 写入规则

- 可复用的方法写成技能。
- 一次性操作不要写成技能。
- 项目专属方法优先写入项目文档。
- 技能文件应简洁、可执行、可验证。
