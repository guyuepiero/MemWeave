# 编译策略与已知坑

大账号模块化编译的完整实操方法，含命令模板与踩坑记录。

## 一、扫描命令模板（每次执行复用）

```bash
# 1. 篇数统计
find . -name "index.md" | wc -l

# 2. album/topic 分布（注意用 while read 防文件名空格切分问题）
find . -name "index.md" | while read f; do awk '/^album:/{print $2;exit}' "$f"; done | sort | uniq -c | sort -rn | head -12

# 3. 完整文章清单（日期|专辑|标题|字节，排序输出）
find . -name "index.md" | while read f; do
  d=$(dirname "$f"); date=$(basename "$d" | cut -d_ -f1)
  title=$(awk -F': ' '/^title:/{sub(/^title: /,"");print;exit}' "$f")
  size=$(wc -c < "$f")
  echo "$date | $title | ${size}B"
done | sort
```

## 二、主题模块化编译（≥155 篇账号）

### 决策标准
- **≤65 篇**：逐篇精编（每篇 1 概念页，系列文章可合并）
- **≥155 篇**：主题模块化（每模块 1 页，含多篇来源清单）
- **中间值**：按内容重合度判断，教程/问答类倾向合并

### 模块划分方法
1. 先按 album 分布 + 标题语义聚类（如 Maxdon：后台操作/关键词/广告基础/16 种打法/广告优化/选品/竞品/跟卖/算法/合规/工具/2026 战略）
2. 每个模块 8-20 篇 → 1 页概念页，页内"详情"按子主题分小节
3. 页面"引用来源"列出该模块全部文章（日期+标题），保证可追溯

### 批量提取要点命令（控制 token 核心手段）
```bash
# 单条：sed 提取正文第 14-40 行（跳过 YAML 头），去图片、去空行、限 6-9 行
sed -n '14,40p' "$f" | sed 's/!\[.*\]//g;s/(images.*//' | grep -v "^[[:space:]]*$" | head -8

# 批量：for 循环一次提取 8-12 篇，head 限制总输出防爆
for f in "目录1/index.md" "目录2/index.md" ...; do
  echo "=====$(basename "$(dirname "$f")")====="
  sed -n '14,40p' "$f" 2>/dev/null | sed 's/!\[.*\]//g;s/(images.*//' | grep -v "^[[:space:]]*$" | head -7
  echo ""
done 2>/dev/null | head -120
```
- 提取后信息不足的篇目再单独全读（`Read` 全文或分段读）
- 重磅文章（系列首篇/方法论长文）必须全文精读，不依赖 sed 摘要

## 四、已知坑与应对

| 坑 | 表现 | 应对 |
|---|---|---|
| 中文/特殊字符文件名 | 路径拼接失败、Read 报错 | 先 `ls -d 2025-08-12*` 定位准确目录名，勿凭记忆拼接 |
| 终端乱码 | 部分 sed 输出显示乱码 | UTF-8 实际正常，内容可用；无需重试 |
| 重复文章 | 同文不同日期（diff 比对大小相同） | `diff <(cat a) <(cat b)` 验证后合并 1 页，来源标注两篇 |
| 图片教程文 | 正文几乎全是截图 | 按标题聚合概述步骤要点，不硬编细节 |
| 工具商推广文 | 卖家精灵/福利/折扣文占比高 | 单独成页并标注"约 N 篇为推广文，价值低" |
| 日期排序重叠 | sort 后 head/tail 输出异常 | 分专辑扫描（按 album 过滤），勿依赖单次全量输出 |
| 长文 | 单篇 >10KB | 分段 Read（limit/offset 150 行一段），勿一次读全 |
| sed 批量改链失败 | `unknown option to 's'` 刷屏 | 链接含 `|` 字符时勿用 `|` 作分隔符，改用 `#`：`sed -i "s#旧#新#g"`；改链前先 `mkdir -p .backup_xxx && cp -r entities concepts topics` 全库备份 |
| 存量断链（缺前缀） | `[[concepts/xxx]]` 实际文件为 `concept-xxx.md` | 全库扫描：`grep -rohE "\[\[(entities|concepts|topics)/[^]]+" --include="*.md" . | sort -u`，逐一验证 `[ -f "$p.md" ]` 后补前缀；带作者前缀的（如 `concept-dongli-xxx`）需按语义对号入座，勿盲目补前缀 |

## 五、会话节奏控制（防 token 失控）

- 单次会话控制 40-70 篇（逐篇）或 1 个大账号（模块化）
- 每批（5-8 篇）完成即汇报进度；会话中期可先固化 index/log 再继续
- 重复确认的信息不二次读取；已写页面不重读验证（用 ls/grep 统计即可）
