# 质量红线："全面 + 准确"细则

主公对知识库的最高要求：**尽量保持全面和准确**。本文件是编译完成后的强制自检清单。

## 一、全面（Completeness）——覆盖无遗漏

### 覆盖核对（每次编译后必做）
```bash
# 总篇数 vs 已编译覆盖篇数必须相等
find RAW/<账号> -name "index.md" | wc -l
# 概念页引用来源中出现的文章日期/标题，与清单比对
```

### 全面性细则
1. **零遗漏**：该来源全部文章必须出现在某个页面的"引用来源"清单中（逐篇或模块化皆可）
2. **来源清单完整**：每页引用来源 = 该模块/该篇的全部文章（日期+标题），不得抽样省略
3. **重复合并留痕**：合并重复文章时，两篇的日期都在来源清单标注（如"01-19/01-20 同文重复"）
4. **专辑全覆盖**：账号下每个 album 至少对应一个页面或一个页内小节
5. **付费/争议内容**：照常收录（主公明确要求含付费文），来源标注清楚

## 二、准确（Accuracy）——忠实原文

### 忠实原文细则
1. **数字逐字一致**：价格、比例、公式、政策条款必须与原文完全一致，禁止四舍五入改写
   - 例：原文"转化率 8%"→ 写 8%，不写"约一成"
   - 例：原文"SPR = 8天预估出单量"→ 原样记录
2. **观点归属清晰**：页面内容默认 = 原文观点；AI 补充/推理必须显式标注
3. **不添加原文没有的结论**：摘要/详情不得引入原文未提及的"补充知识"充当原文观点
4. **术语不篡改**：专有名词（ACoS/TACOS/SPR/VP 评价等）保持原文写法，不统一改写

### 矛盾标注（知识库灵魂功能）
遇到以下情况**必须**显式标注，不得悄悄二选一：
```markdown
> ⚠️ **存疑标注**：原文提到"二手商品价格影响秒杀价"，该说法与平台现行规则存疑，
> 系原文观点（2025-02-17），非本站确认结论，使用前建议向亚马逊后台核实。
```
触发场景：
- 原文内部矛盾（同一作者前后说法不一致）
- 原文说法与主流认知/平台规则冲突
- 不同来源对同一主题结论相反（如"广告关联是否存在"）
- 时效性强的政策类内容（注明发布日，避免过时误导）

### 区分"原文事实"与"AI 推理"
| 类别 | 处理 |
|---|---|
| 原文明确陈述 | 直接收录，标来源日期 |
| 原文"大胆猜测"（如 ABA=PC 搜索人数） | 收录但标注"原文猜测属性" |
| AI 从原文推导的延伸结论 | 显式写"AI 推论："前缀，或放入"关联"而非"详情" |
| AI 外部知识（未在原文） | 不写入详情；仅在"关联"中提示可参考其他页面 |

## 三、防幻觉清单（编译时不犯）

- [ ] 不编造原文没有的案例/数字/政策条款
- [ ] 不确定的篇目（sed 提取不全）→ 全文重读后再编译，不凭标题猜内容
- [ ] 标题与正文不符（常见于公众号营销标题）→ 以正文为准
- [ ] 不把"某作者观点"写成"平台规则"或"行业共识"
- [ ] 涉及灰产/黑科技内容（翻新、换区、合并）→ 收录但加风险警示，不提供操作鼓励

## 四、交叉引用质量

- 每页 ≥2 个 `[[关联]]`（硬性要求）
- 优先跨来源互链（如"马甲打法"页同时链 Maxdon、Luke、阿C哥的相关页）
- 同主题系列页必须互链（如竞价策略实验 1/2/3）
- 未匹配到的概念写"待关联"，不硬凑链接

## 五、完成后三查

1. **一查覆盖**：`grep` 统计已编译页数 vs 总篇数，账实相符
2. **二查准确**：抽查 3-5 页，核对关键数字与原文一致、矛盾已标注
3. **三查互链**：随机点 3 页，关联链接均指向真实存在的文件（`ls` 验证文件名存在）
