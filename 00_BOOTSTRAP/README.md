# 00_BOOTSTRAP 启动目录说明

本目录是 Agent 进入 AI_OS 后的启动入口。

它的作用是告诉 Agent：先读什么、后读什么、如何控制 Token、如何避免一次性加载过多内容。

## 目录结构

```text
00_BOOTSTRAP/
├── README.md
├── BOOTSTRAP.md
└── TOKEN_BUDGET.md
```

## 文件用途

### BOOTSTRAP.md

Agent 启动协议。

用于定义进入 AI_OS 后的标准读取流程：

```text
启动
-> 读取启动协议
-> 读取规则索引
-> 加载系统规则
-> 读取用户上下文
-> 读取当前状态
-> 判断任务
-> 按需加载资源
```

### TOKEN_BUDGET.md

Token 预算规则。

用于要求 Agent 在任务开始前预估任务规模、读取范围、工具调用次数和输出规模。

当任务预计消耗较高时，必须先拆分任务或缩小读取范围。

## 使用规则

- 每个 Agent 启动时应先读取本目录。
- 不要在这里放项目内容、用户偏好、技能说明或知识资料。
- 本目录只负责“如何启动”和“如何控制上下文预算”。
