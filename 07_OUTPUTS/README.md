# 07_OUTPUTS 输出资产目录说明

本目录用于保存 Agent 生成的可复用成果。

它不是临时缓存，也不是所有聊天回答的备份区。只有未来可能再次使用、交付、整理或复盘的成果才需要保存。

## 目录结构

```text
07_OUTPUTS/
├── README.md
├── CODE/
├── DOCUMENTS/
├── DATA/
└── TOOLS/
```

## CODE/ 通用代码输出区

### 用途

保存跨项目可复用的代码片段、脚本、示例程序或工具代码。

### 适合放入

- 通用脚本
- 示例代码
- 可复用函数
- 小型工具代码
- 非项目专属代码文件

### 不适合放入

- 某个项目的正式源码
- 临时代码草稿
- 未验证的大段生成代码

项目专属代码应优先放到：

```text
04_PROJECTS/<PROJECT>/CODE/
```

## DOCUMENTS/ 文档输出区

### 用途

保存 Agent 生成的文档类成果。

### 适合放入

- 报告
- 方案
- 总结
- 说明书
- 模板
- 计划文档
- 交付文档

### 不适合放入

- 项目内部文档
- 原始知识资料
- 会话总结

项目专属文档应优先放到：

```text
04_PROJECTS/<PROJECT>/DOCS/
```

## DATA/ 数据输出区

### 用途

保存 Agent 生成、清洗、转换或分析后的通用数据文件。

### 适合放入

- 清洗后的数据
- 分析结果
- 表格文件
- JSON / CSV / YAML 数据
- 可复用数据样例

### 不适合放入

- 项目专属数据
- 原始知识库资料
- 临时中间文件

项目专属数据应优先放到：

```text
04_PROJECTS/<PROJECT>/DATA/
```

## TOOLS/ 工具输出区

### 用途

保存可复用工具、自动化脚本、辅助程序和工具说明。

### 适合放入

- 自动化脚本
- 小工具
- 命令行工具说明
- 数据处理工具
- 检查脚本

### 不适合放入

- 某个项目私有工具
- 未完成工具草稿
- 只用一次的临时脚本

## 元数据建议

重要输出建议附带元数据：

```yaml
生成Agent:
日期:
所属项目:
使用技能:
说明:
来源任务:
验证状态:
```

## 写入规则

- 未来可能复用的成果才保存。
- 一次性回答不必强行保存。
- 项目专属成果优先进入项目目录。
- 跨项目可复用成果进入 `07_OUTPUTS/`。
- 保存重要成果后，必要时更新 `CURRENT_CONTEXT.md` 或项目 `TASK.md`。
