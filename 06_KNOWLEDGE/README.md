# 06_KNOWLEDGE 知识库目录说明

本目录用于保存用户的个人知识库。

知识库的作用是给 Agent 提供外部知识来源，而不是作为每次任务都要完整读取的上下文。

知识来源可以包括：

- 微信公众号文章
- X / Twitter 内容
- YouTube 视频字幕或总结
- 抖音内容
- 网页文章
- 课程笔记
- 书籍摘录
- 研究报告
- 用户自己的长期资料

## 目录结构

```text
06_KNOWLEDGE/
├── README.md
├── RAW/
├── PROCESSED/
└── VECTOR_DB/
```

## RAW/ 原始资料区

### 用途

保存未经整理或轻度整理的原始资料。

这里是知识库的“原始仓库”，用于保留来源内容，方便以后追溯。

### 适合放入

- 微信公众号文章原文
- YouTube 字幕原文
- 抖音视频文案
- X 长帖或推文合集
- 网页文章摘录
- PDF 转出的原始文本
- 临时收藏但还没整理的资料

### 不适合放入

- 已经结构化整理好的知识卡片
- 项目专属决策
- 当前任务状态
- Agent 生成的最终报告

### 读取规则

默认不读取。

只有当 `PROCESSED/` 中的信息不足，或需要确认原始来源时，才读取 `RAW/`。

## PROCESSED/ 整理知识区

### 用途

保存经过 AI 或人工整理后的结构化知识。

这里是 Agent 最常使用的知识区。

### 适合放入

- 主题总结
- 知识卡片
- 文章精华
- 视频总结
- 方法论整理
- 术语解释
- 可复用观点
- 结构化笔记

### 不适合放入

- 未处理的大段原文
- 临时聊天记录
- 项目当前状态
- 无来源、无主题、无标签的散乱内容

### 建议格式

```markdown
# 标题

## 来源

来源链接或来源说明

## 主题

知识所属主题

## 摘要

核心内容摘要

## 关键观点

- 观点 1
- 观点 2
- 观点 3

## 可复用场景

这条知识适合在哪些任务中使用

## 标签

#AI #编程 #商业 #写作
```

### 读取规则

Agent 需要外部知识时，应优先读取本目录中的整理内容。

读取顺序：

```text
主题索引
-> 相关知识卡片
-> 目标总结
-> 必要时追溯 RAW 原文
```

## VECTOR_DB/ 向量检索区

### 用途

保存未来 RAG 检索需要的向量索引、嵌入文件、数据库文件或检索配置。

这里不是给 Agent 直接阅读的内容区，而是给检索工具或自动化脚本使用的索引区。

### 适合放入

- 向量数据库文件
- embedding 文件
- 索引元数据
- RAG 配置
- 检索缓存
- 分块后的知识索引

### 不适合放入

- 普通 Markdown 知识笔记
- 原始文章
- 当前项目文件
- Agent 输出报告

### 读取规则

普通 Agent 不直接读取本目录。

只有在调用 RAG、搜索脚本、知识检索工具时才使用。

## 知识读取总规则

不要默认加载整个知识库。

推荐顺序：

```text
先看索引或主题
-> 读取 PROCESSED 中的摘要
-> 需要细节时读取目标资料
-> 需要追溯时读取 RAW
-> 需要大规模召回时使用 VECTOR_DB
```

## 知识写入总规则

- 原始内容进入 `RAW/`。
- 整理后的知识进入 `PROCESSED/`。
- 检索索引进入 `VECTOR_DB/`。
- 项目专属知识应同步沉淀到对应项目的 `MEMORY.md`。
- 用户长期偏好不要写入知识库，应写入 `02_USER_CONTEXT/`。
