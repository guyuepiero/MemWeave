# SKILL_SYNC_RULE.md —— 技能同步规则（P2）

## 目的

保证工作区框架内的技能副本**始终与权威源一致**，任何 Agent 通过框架拿到的技能都是最新版，杜绝"跨对话调用到老版本"。

## 技能分类与存放

| 类型 | 判定 | 存放 |
|---|---|---|
| A. 跨 Agent 可复用技能 | 不依赖单一平台（如 WorkBuddy）特有环境，OpenClaw / Trae / Codex / Hermes 等也能跑 | 权威源 + **工作区副本** `05_SKILLS/COMMON/<技能名>/`（含 SKILL.md 与全部运行文件） |
| B. WorkBuddy 独占技能 | 仅 WorkBuddy 调用、依赖其环境 | 权威源 `~/.workbuddy/skills/<技能名>/`，框架 `05_SKILLS/INDEX.md` 仅登记指针 |

## 强制动作：技能更新即同步

**任何 Agent 在会话中修改/升级/新增技能（SKILL.md、脚本、映射、配置任一文件）后，必须：**

1. 若属 A 类（或不能确定），**立即把改动后的完整技能目录同步复制**到 `05_SKILLS/COMMON/<技能名>/`；
2. 若技能尚无副本：新建副本目录并复制；
3. `diff -r` 校验副本与权威源一致（排除 `__pycache__` 等缓存）；
4. 更新 `05_SKILLS/INDEX.md` 对应条目（用途/版本要点），保持登记最新；
5. 新技能首次登记：在 INDEX.md 按分类加行。

> 权威源只有一份（`~/.workbuddy/skills/` 或技能实际安装处）；副本的唯一目的是供框架内其他 Agent 使用。**禁止把副本当权威源改**——改必先从权威源同步。

## 命名与卫生

- 副本目录名 = 技能名（去平台后缀如 `__skillhub`）；
- 不复制缓存/临时产物（`__pycache__`、`out/`、截图）；
- 副本与权威源漂移时：以权威源为准覆盖副本，并 diff 验证。

## 违反后果

框架内 Agent 使用旧版技能 → 产出与权威口径不一致 → 返工。同步动作应视为技能更新的**组成部分**，不可省略。
